# Ресурсы изображений

Четыре портрета созданы встроенным генератором изображений. Исходный квадратный знак FitCalculator переработан им же в круглый знак с прозрачным внешним полем. Стандартный силуэт — вектор Android.

Финальные PNG находятся в `app/src/main/res/drawable-nodpi/`; вектор — `app/src/main/res/drawable/avatar_default.xml`. Кадрирование до круга выполняется в Compose, поля иконки запуска заданы ресурсом `launcher_foreground.xml`.

Точные запросы для портретов:
