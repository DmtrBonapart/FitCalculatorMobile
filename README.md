## Что добавлено

- Круглый логотип на входе и регистрации, адаптивная иконка с прозрачным фоном и безопасными полями, оформление системного экрана запуска Android 12+.
- Нажатие на имя/аватар на главной, в статистике и дневнике открывает профиль.
- Пять локальных аватарок: силуэт, парень брюнет, парень блондин, девушка брюнетка, девушка блондинка. В аккаунте Supabase сохраняется только `avatar_id`; изображения остаются внутри приложения. Выбор сохраняется отдельно от остальных полей профиля.
- Дневник содержит раскрываемые карточки «Завтрак», «Обед», «Ужин», «Перекус» с суммами КБЖУ и прежними карточками записей внутри. Пустые приёмы пищи тоже отображаются. Старые нестандартные названия приёмов пищи сохраняются отдельными группами.
- Кнопка «Создать продукт» на дневнике и в каталоге. В форме указываются название, существующая категория и КБЖУ на 100 г. Поддерживаются запятая и точка в дробных значениях. После сохранения продукт появляется в общем каталоге, откуда его можно добавить в дневник. По текущей схеме базы каталог общий для пользователей.
- Логика загрузки и сохранения остаётся в ViewModel. Новые расчёты и проверка данных вынесены в отдельные Kotlin-классы.
- В действующей базе Supabase каталог расширен с 5 до 20 продуктов. Существующие строки сохранены, схема и правила доступа не изменялись. `seed_catalog.sql` содержит выполненное добавление с проверкой существующих названий.

## Как обновить существующий проект

Рекомендуется архив `FitCalculatorMobile_update_2026-11-03.zip`: он содержит только изменённые и новые файлы.

1. Сделайте копию вашей папки проекта.
2. Откройте `C:\Users\User\AndroidStudioProjects\fit2\FitCalculatorMobile` — папку, где находятся `app`, `gradle` и `settings.gradle.kts`.
3. Перенесите туда содержимое архива обновления с объединением папок и заменой одноимённых файлов. Папку `app` удалять не нужно.
4. Нажмите Run в Android Studio.

Архив обновления не содержит файлов настроек Gradle, `secrets.properties` или `local.properties`; ваши рабочие настройки сохранятся. SQL повторно выполнять не требуется: каталог уже обновлён.

## Как открыть полный архив отдельно

Распакуйте `FitCalculatorMobile_project_2026-11-03.zip`. Скопируйте свой рабочий `secrets.properties` из текущей папки проекта в корень распакованной `FitCalculatorMobile`. Откройте её в Android Studio. `local.properties` создаётся для установленного Android SDK. Не заменяйте URL Supabase на localhost.

Из-за ограничений среды проверки Gradle и Kotlin запускались в одном процессе; единственный Java-файл `BuildConfig.java` компилировался тем же JDK напрямую через временный сценарий вне проекта. Эти параметры и сценарий в архив не включены. Обычные настройки сборки проекта сохранены.
